# dyscalculia-docs

Source of [docs.dyscalculia.io](https://docs.dyscalculia.io): the developer docs for the
[MCP server](https://github.com/Dyscalculia-io/dyscalculia-mcp),
the [dataset](https://github.com/Dyscalculia-io/dyscalculia-data) and the
[embeddable number games](https://github.com/Dyscalculia-io/dyscalculia-embed).

Static HTML generated by `build.mjs`:

```bash
npm install
npm run build     # writes dist/
npm run serve     # http://localhost:4000
```

- Every page is a list of blocks (`build.mjs`); the same blocks produce the HTML, `llms.txt` and `llms-full.txt`.
- The **tool reference is generated from the `dyscalculia-mcp` package**: the build starts the server, reads `tools/list` and
  calls each tool, so the docs cannot drift from the server. Every number comes from `dyscalculia-data`, and the game catalog
  (`/embed-catalog.json`) is the `catalog.json` of `dyscalculia-embed`. After releasing a new package version, bump the dependency
  here and redeploy.
- The build refuses to run with a `dyscalculia-embed` older than 0.1.0 (`ALLOW_OLD_EMBED=1` overrides it for local work only).
- The MCP client setup text (`content/shared.json`) and the platform guide (`content/platforms.json`) are snapshots of the site's
  `content/developers.ts` and `content/embedGuide.ts`: `npm run sync` regenerates them from a site checkout
  (`DYSC_SITE=/path/to/dyscalculia_marketing`). Client menus change; update both places when one does.
- Root files (the IndexNow key file) live in `public/` and are copied to the site root.
- Deploy: `Dockerfile` (Node build, then `server.mjs`, a dependency-free static server on port 8080, `/health`). Pushing this
  repository does not deploy it by itself: trigger a deploy after the packages are on npm. Code MIT, statistics compilation CC BY 4.0.
